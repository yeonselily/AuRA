# AuRA
A music discovery app that takes a plaintext description of the user’s mood and generates a playlist that fits the mood in one click. 

## Build
**NOTE:** Will NOT work without the proper .env.local file. This file contains private keys, so it cannot be made public. Please use our deployed site!<br>(awesome link goes here)

`git clone https://github.com/yeonselily/AuRA.git`

`npm install`  

`npm run dev` or `npm run start`

Open http://localhost:3000
